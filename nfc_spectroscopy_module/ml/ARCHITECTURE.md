# Machine Learning Architecture for Dielectric Spectroscopy

This document details the Machine Learning pipeline designed to classify complex fluid formulations (e.g., organic extracts, soaps, biopolymers) using their electromagnetic signatures. By analyzing the time-series data of 13.56 MHz signal attenuation generated by the ESP32/RC522 hardware-in-the-loop setup, we can characterize material density and dielectric properties.

## 1. System Overview

The ML pipeline consists of three main stages:
1. **Data Acquisition (Labeled Recording):** A specialized script (`ml_data_collector.py`) records time-series data while a user specifies a target label (e.g., "water", "soap_50_percent", "empty"). This generates a rich dataset with temporal dynamics.
2. **Feature Extraction (Time-Domain):** Raw signal data (`success_rate_pct` and `avg_latency_us`) is processed using sliding windows. Within each window, statistical features are calculated.
3. **Classification:** A Machine Learning model (Random Forest Classifier) is trained on the extracted features to predict the formulation/density class based purely on its electromagnetic interference pattern.

## 2. Feature Engineering

Because we are dealing with high-frequency temporal data representing proxy metrics, raw points alone are not robust. We extract features over a sliding window (e.g., 2 seconds of data at 100 Hz = 200 samples).

Key features extracted per window include:
*   **Success Rate Drop:** Mean, Median, Minimum, and standard deviation (Variance) of `success_rate_pct`.
*   **Latency Metrics:** Mean, Maximum, and Variance of `avg_latency_us`.
*   **Latency Decay Slope (Derivative):** The linear trend (slope) of the latency over the window, capturing how quickly the magnetic coupling degrades or stabilizes when the material is introduced.

## 3. Machine Learning Model Selection

We utilize a **Random Forest Classifier** (`scikit-learn`) as the baseline model.
*   **Why Random Forest?** It handles non-linear relationships well, requires minimal feature scaling compared to SVMs or Neural Networks, and provides excellent feature importance metrics (allowing us to see if latency or success rate is driving the classification).
*   **Cross-Validation:** The pipeline implements a stratified train-test split to evaluate accuracy and prevent overfitting on specific formulation classes.

## 4. Pipeline Execution Flow

1.  **Collect Data:** Run `ml_data_collector.py` for each material/fluid to build a comprehensive CSV dataset.
2.  **Train & Evaluate:** Run `ml_pipeline.py` pointing to the collected CSV. The script will:
    *   Load and clean the data.
    *   Apply sliding-window feature extraction.
    *   Train the Random Forest model.
    *   Output classification metrics (Accuracy, Precision, Recall) and feature importance.
    *   Save the trained model (`nfc_dielectric_model.pkl`) for future real-time inference.
